# Business goals

This is a transparent personal reference implementation for a Java meetup. It demonstrates that access to repository files is different from selection of the right context.

The useful outcome is a coding task whose implementation, tests, documentation and intent tell the same story. Markdown and Git keep the mechanism visible; an enterprise version could replace the DAO with managed sources and add governance.
